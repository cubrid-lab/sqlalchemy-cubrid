## Re-release of v1.2.2

The `v1.2.2` git tag had been created earlier on an older commit (`475d9d2`, pre-async-dialect, pre-#120 fix), so the PyPI 1.2.2 artifact built from that tag was missing both the [#120](https://github.com/cubrid-lab/sqlalchemy-cubrid/issues/120) fix AND the `cubrid.pycubrid` / `cubrid.aiopycubrid` entry points introduced in #119.

**PyPI 1.2.2 will be yanked.** Please use 1.2.3.

### Fixed (originally intended for 1.2.2)

- **Alembic autogenerate false-positive diffs** (#120):
  - `get_indexes()` filters CUBRID's auto-created PK/FK indexes
  - `get_foreign_keys()` rewritten to parse `SHOW CREATE TABLE` (the `db_constraint` view is not queryable in CUBRID 11.x)
  - `get_unique_constraints()` rewritten to parse `SHOW CREATE TABLE`
- **`compare_type` for unbounded VARCHAR**: `CubridImpl.compare_type()` now treats CUBRID's `VARCHAR(1073741823)` as equivalent to SQLAlchemy's `Text()`/`CLOB()`/`String()` (no length)

**Full Changelog**: https://github.com/cubrid-lab/sqlalchemy-cubrid/compare/v1.2.2...v1.2.3
