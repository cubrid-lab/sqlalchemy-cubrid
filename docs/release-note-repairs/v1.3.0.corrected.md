- **FK parsing with ON DELETE/ON UPDATE** referential actions (#135)
- **Multi-table UPDATE** — `UPDATE ... JOIN ... SET` syntax (#137)
- **FULL OUTER JOIN / LATERAL rejection** with `CompileError` (#138)

- **`get_isolation_level()` fallback** — returns canonical `"READ COMMITTED"` (#140)
